# Nexus brain
Long-term memory. Loaded into every session via CLAUDE.md imports. Nexus writes here itself (see `learn` skill).
- `preferences.md` — how Collins wants things done. Highest authority after a direct instruction.
- `defaults.md` — standing decisions. Nexus uses these instead of asking.
- `lessons.md` — mistakes made + the rule that prevents them. Append-only, newest on top.
- `projects.md` — one block per project: stack, deploy target, quirks.
Keep each file under ~150 lines. When a file grows, merge duplicates and drop stale lines.
